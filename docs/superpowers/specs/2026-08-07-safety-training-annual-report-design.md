# 안전교육 연간 보고서 — 감사·점검 대비 확인 문서

2026-08-07 · 사용자 승인안 (A안: 연도별 보고서 화면)

## 문제

감사·점검 때 "근로자별·연도별로 교육을 했는가"를 보여줄 문서가 없다. 홈의
인원별 이수 현황은 이번 반기만 보여주고, 알림·버튼이 섞여 인쇄에 못 쓴다.
데이터는 이미 완결적이다 — 완성 일지 meta(일자·종류·시간·참석자 스냅샷) + 직원 명부.

## 결정

새 데이터·스키마 없이 **열 때마다 계산하는 인쇄용 보고서 페이지 하나**.
집계 결과를 문서로 발행(B안)하지 않는다 — 실제 증빙은 서명된 일지고,
집계표는 언제든 같은 숫자로 재생성된다.

## 설계

- **라우트** `/modules/safety-training/report?year=YYYY` (기본 올해 KST).
  연도 전환은 일지가 존재하는 연도만 링크로. 홈 헤더에 진입 버튼.
- **집계** `personProgress`에 선택 인자 `half: Half`(기본 `halfOfKst(now)`)를
  추가해 지난 연도 상·하반기를 각각 집계. 기존 호출부 무변경.
  옛 일지 시간 못 읽으면 0시간 등 기존 판정 규칙 그대로.
- **화면·인쇄물** (위→아래, `PrintStyle`+`PrintButton` 재사용):
  1. 연간 요약 — 반기별 직군 판정(현재 활성 명부 기준, 각주 명기), 관리감독자,
     채용 시(그해 입사자). 법적 근거 `LEGAL_BASIS`.
  2. 근로자별 연간 집계표 — 인원 × 상·하반기 시간/판정 · 채용 시 · 참석 회차.
  3. 개인별 이수 카드 — 참석 교육 목록(일자·종류·제목·시간·**문서번호**).
     문서번호가 서명된 원본 일지로의 증빙 연결. 인쇄 시 한 사람 한 장.
- **퇴사자** 명부 전체(비활성 포함)를 읽되, 비활성은 그해 참석 기록이 있을 때만
  표에 나온다. 퇴사일이 없으므로 비활성의 미이수는 판정하지 않고 "퇴사"로
  표기한다 — 3월 퇴사자를 하반기 미이수로 찍으면 거짓 기록이 된다.

## 추가 결정 — 관리감독자(소장) (같은 날 후속 승인)

소장을 반기 집계에 두면 거짓 기록이 된다: 별표 4에서 관리감독자의 정기교육은
반기 6/12시간이 아니라 **연간 16시간**이다. 또 관리감독자 교육은 등록기관
위탁·본사 집합교육이 관행이라(자체교육은 소장이 자기를 교육하는 그림) 증빙이
앱 일지가 아니라 **수료증**인 경우가 기본값이다.

- `TrainingStaff.supervisor`(체크) + `extTrainings Json`([{date, org, hours}]).
- 관리감독자는 `personProgress`(반기)에서 빠지고, `supervisorProgress`가
  연 단위로 앱 일지 + 외부 이수를 합산해 16시간 판정.
- `complianceOf.supervisor`: 표시된 사람이 있으면 전원 16h 판정, 없으면 예전
  기준(그해 실시 여부)으로 폴백 — 기존 단지 화면이 갑자기 바뀌지 않게.
- 외부 이수는 명부 화면에서 등록(이수일·기관·시간). 원본 증빙은 수료증(종이),
  보고서 카드에는 "수료증 별도 보관"으로 표기.
- 채용 시 교육은 관리감독자에게도 기존과 동일 적용(더 엄격한 쪽, 조문 판단 유보).
