# 사용법 페이지(/guide) 설계

> 2026-08-09 사용자 결정: 범위 = 전체 페이지 + 모듈별 섹션(모듈 홈에서 해당 섹션으로 점프),
> 표현 = 단계 카드 + 흐름 요약(화면 캡처 없음 — 화면이 바뀔 때마다 거짓말이 되는 안내를 만들지 않는다).
> 시점 = 지금(판매 중 6개 모듈 기준). 남은 모듈은 출시 커밋에서 섹션을 같이 추가한다.

## 1. 문제

모듈이 7개(코어 포함 화면 60여 개)가 되면서 "어떤 업무를 어느 모듈로, 어떤 순서로
하는가"를 설명하는 자리가 없다. 지금 안내 장치는 홈의 시작 가이드 4단계(마스터만,
완료되면 사라짐)와 화면 안 문구뿐 — 처음 온 사용자가 전체 그림을 볼 곳이 없다.
셀프서비스 SaaS에서 가이드 부재 = 문의 폭증 = 운영자 개입이므로 출시 조건에 해당한다.

## 2. 구조

- **라우트**: `/guide` — `(app)` 레이아웃 안, 로그인만 요구(구독 무관 — 미구독 모듈
  섹션도 보여 준다. 뭘 해주는 모듈인지 아는 것 자체가 구독 판단 재료다).
- **데이터**: `src/lib/guide.ts` 순수 데이터 파일 하나. 모듈 섹션은 모듈 id로 키를
  건다. **화면은 레지스트리의 `isActive` 모듈 중 guide 데이터가 있는 것만 렌더** —
  데이터가 없는 모듈은 목차에서 자동으로 빠지므로 빈 섹션 사고가 없다.
- **레이아웃 (2026-08-09 시안 비교 후 확정 — 시안 A)**: 2단 분할. 왼쪽 목록은
  고정(`lg:sticky lg:top-20`), 오른쪽에는 **고른 항목 하나만** 그린다. 모바일은
  목록이 가로 스크롤 칩 줄.
  - 처음 만든 세로 나열은 폐기했다: 목차를 누르면 먼 거리를 스크롤하는데 앱 헤더가
    sticky(h-14)라 착지한 카드 제목이 헤더 뒤로 들어가 잘려 보였다. 한 번에 하나만
    그리면 그 이동 자체가 없다.
  - 선택 시 `history.replaceState`로 해시를 맞춘다(링크 복사 가능). push하지 않는
    이유: 뒤로가기가 항목 사이를 되짚으면 사용법을 빠져나갈 수 없다.
  - 해시로 들어오거나 아래로 내려간 상태에서 항목을 바꾸면 본문 위를 헤더 아래로
    되돌린다(72px). 이미 위에 있으면 스크롤하지 않는다.
- **섹션 구성**(순서 고정):
  1. 처음 시작 (코어 — 항상)
  2. 모듈 섹션들 (레지스트리 `sortOrder` 순)
  3. 문서함·알림·문의 (코어 — 항상)
- **섹션 내부**: 한 줄 정의 → "이럴 때 씁니다" → 흐름 요약(단계 이름을 → 로 이은
  한 줄 칩) → 번호 붙은 단계 카드(제목 + 2~3문장 + 선택적 [바로 가기] 링크) →
  "알아 두면 좋아요" 팁 목록(선택).
- **진입점 3곳**:
  - 사이드바 `coreItems`에 "사용법"(BookOpen, 문서함과 단지 관리 사이) — 모바일
    드로어는 SideNav를 재사용하므로 자동 포함.
  - 각 모듈 홈 PageHeader에 [사용법] ghost 버튼(CircleHelp) → `/guide#<moduleId>`.
    6개 모듈 홈 수정.
  - 홈 시작 가이드는 손대지 않는다(역할이 다르다 — 그쪽은 설정 완료 체크).

## 3. 섹션별 내용 (단계 목록 확정 — 문구는 구현에서)

**처음 시작**: ① 단지 정보 입력(주소·세대수·전화 — 공고문 하단에 실린다)
② 세대 등록(엑셀 한 번 — 독촉장·공지가 같이 쓴다) ③ 직원 계정(권한 3종 설명 한 줄)
④ 모듈 구독(무료 체험 → 카드 등록 → 해지도 클릭 한 번). 팁: 데이터는 단지 단위로
분리, 탈퇴는 30일 유예.

**AI 공지문 완성**: 유형 선택 → 아는 것만 입력 → AI 초안(10~30초) → 초안 화면에서
사진 첨부·내용 수정 → [공지문 완성] = 문서번호 → 인쇄·게시. 팁: 반복 공지는 지난
공지 복제가 빠르다 / 잘못 낸 공지는 폐기로 남긴다.

**AI 기안·결재**: ⓪ 결재선 설정(설정 > 결재선 — 내부 순서 + 회장·감사는 계정 없이
이름·연락처만) → 다섯 항목 입력(금액이 계약 방식·결재선을 자동 판정) → 초안
확인·수정 → 상신 → 내부 순차 결재, 외부는 서명 링크(복사 또는 메일) → 완료되면
입주민 공고문 자동, 완료보고·지출결의는 버튼으로 파생. 팁: 지난 기안 복제 /
소장 전결 한도(설정)를 넣으면 회장 결재가 빠지는 경우.

**AI 안전교육일지**: 직원 명부 등록(직군·입사일 — 입사일이 채용 시 교육 판정 기준)
→ 교육 실시 후 종류·주제 선택 → AI 일지 초안 → 참석자 체크 → 완성·인쇄(서명 보관)
→ 반기 이행 현황과 연간 보고서는 자동 집계. 팁: 사진·수료증 첨부 / 마감 D-30·D-7
알림.

**미납 독촉장**: 세대 등록 확인 → 미납 세대 선택 또는 엑셀 업로드 → 단계 선택
(납부 안내 → 납부 최고 → 내용증명) → 한 번에 생성·인쇄 → 납부 확인 표시(다음
회차 단계 제안의 기준). 팁: 내용증명은 우체국 제출용 수신인 목록까지 / 단지
우편번호를 설정에 넣어 둘 것.

**법정점검 대장**: 설정 마법사로 해당 항목 켜기(질문 8개) → 현황판에서 도래일·지연
확인(주기는 앱이 센다) → 점검 후 기록 작성(즉시 문서번호) → 지적사항은 후속 조치
추적 → 감사 서류철에서 기간 묶음 인쇄. 팁: 도래 알림(D-리드타임·D-7) / 기준일이
없으면 주기를 못 세니 항목 관리에서 입력.

**설비·수선 이력**: 설비 대장 올리기(엑셀 — 없어도 기록은 된다) + 과거 이력 이관
→ 수선 30초 기록(현장 폰, 설비 미지정 허용) → 끝나면 조치 완료 → 설비 상세에서
이력·12개월 집계·반복 고장 경고 → 이력 카드 인쇄(인수인계·교체 설득 자료) →
교체 품의 만들기(기안·결재 구독 시). 팁: 지적사항 있는 점검 기록에서 [수선 등록].

**문서함·알림·문의**: 모든 모듈의 문서가 한 문서함에 자동 채번으로 쌓인다(통합
검색 Ctrl K) → 알림 센터(도래·결재·마감) → 막히면 고객 문의(앱 안에서 접수·답변).

## 4. 하지 않는 것

- 화면 캡처·이미지 (유지보수 부담 + 낡으면 거짓 안내), 검색(브라우저 찾기로 충분),
  권한별 필터(권한 제약은 문구로 — "마스터·매니저만"), 동영상, FAQ 형식,
  미구현 모듈(minutes·contracts·complaints) 섹션.
- 모듈 출시 절차에 "guide.ts 섹션 추가"를 편입 — `isActive: true`와 같은 커밋
  (동작-문구 동기 규칙). 남은 세 모듈의 개발 프롬프트에 이 한 줄을 추가한다.

## 5. 검증

- 미구독 모듈 섹션의 [바로 가기]는 기존 동작대로 `/subscriptions`로 리다이렉트 —
  가이드가 잠금 유도 배너 노릇을 하지 않는다(링크는 섹션 안 단계 카드에만).
- guide 데이터에 있는 모듈 id가 레지스트리에 없거나 비활성이면 섹션이 안 나온다
  (렌더 필터 확인).
- 사이드바·모바일 드로어에 메뉴 노출, 모듈 홈 6곳 버튼 → 해당 앵커 착지.
- UI 문구 규칙: '—' 연결 금지(줄바꿈·마침표), 타이포 공용 체계(text-2xl/lg/sm/xs).
